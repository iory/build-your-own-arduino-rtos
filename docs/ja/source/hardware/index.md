# 四脚ロボットの組み立て

第13章では、自作 OS でサーボを制御して四脚ロボットを歩かせます。
ここではそのハードウェア準備をまとめます。

## 部品表（BOM）

| 品目 | 数量 | 備考 |
|---|---|---|
| サーボモータ | 8 | 各脚 2 自由度 × 4 脚 |
| 3D プリント部品（胴体・脚） | 一式 | データは公開準備中 |
| Arduino UNO R4 WiFi | 1 | 本体 |
| サーボ用電源 | 1 | サーボ 8 個ぶんの電流に注意 |

```{note}
3D プリントデータ・詳細な組立手順書は公開準備中です。
組立手順は CAD から自動生成した図付きの手順書として提供予定です。
```

## 組み立ての流れ

1. 胴体にサーボを固定する
2. 脚を組み立てる（左右 2 脚ずつ）
3. 脚を胴体側サーボのホーンに取り付ける
4. 配線して通電、第13章のキャリブレーションへ

## 安全上の注意

- サーボ電源と USB 電源は分離し、GND を共通にすること
- 初回通電時はサーボを機体に取り付けない状態でキャリブレーション
  すること（想定外の位置に勢いよく動くことがあります）
