## 組み立ての流れ

1. 各サーボに**ユニークな ID を振る**（1 個ずつ接続して設定。組み込む前に）
2. 胴体にサーボを 4 個固定する（M3×6）
3. 脚を組み立てる（左右 2 脚ずつ。サーボ + ブラケット + リンク）
4. 脚を胴体側サーボのホーンに取り付ける（M3×6）
5. 配線して通電、**組み上がった状態でソフトウェア的に 0 点（原点）を取る**
   （第13章のキャリブレーション）

詳細は [組み立て手順](assembly.md) の 3D ビューアを参照してください。

3D プリントデータ（STL）と印刷設定は [部品表](bom.md) にあります。

## 安全上の注意

- サーボ電源と USB 電源は分離し、GND を共通にすること
- 通電時にサーボが想定外の位置へ勢いよく動くことがあるので、
  機体から手を離して電源を入れること
- 床を歩かせるときは AC アダプターではなくバッテリーを使うこと
  （ケーブルを引きずると危険。詳細は [部品表](bom.md)）
