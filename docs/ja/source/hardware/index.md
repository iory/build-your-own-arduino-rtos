## 組み立ての流れ

1. サーボ単体を [キャリブレーション](#安全上の注意)（機体に取り付ける前に）
2. 胴体にサーボを 4 個固定する（M3x6）
3. 脚を組み立てる（左右 2 脚ずつ。サーボ + ブラケット + リンク）
4. 脚を胴体側サーボのホーンに取り付ける（M3x4）
5. 配線して通電、第13章のキャリブレーションへ

詳細は [組み立て手順](assembly.md) の 3D ビューアを参照してください。

```{note}
3D プリントデータ（STL）は公開準備中です。外形寸法・印刷設定は
[部品表](bom.md) にあります。
```

## 安全上の注意

- サーボ電源と USB 電源は分離し、GND を共通にすること
- 初回通電時はサーボを機体に取り付けない状態でキャリブレーション
  すること（想定外の位置に勢いよく動くことがあります）
- 床を歩かせるときは AC アダプターではなくバッテリーを使うこと
  （ケーブルを引きずると危険。詳細は [部品表](bom.md)）
