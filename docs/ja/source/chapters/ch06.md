# 第6章: メモリ保護

MPU を使ってタスク同士のメモリを守り、暴走を検出します。

## サンプルコード

- ディレクトリ: `code/06_memory_protection`
- ビルドと書き込み:

```bash
pio run -d 06_memory_protection -t upload
pio device monitor -b 115200
```

コードを見る: [code/06_memory_protection](https://github.com/iory/build-your-own-arduino-rtos/tree/main/code/06_memory_protection)
