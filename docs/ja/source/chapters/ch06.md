# 第6章: メモリ保護

MPU を使ってタスク同士のメモリを守り、暴走を検出します。

## サンプルコード

- ディレクトリ: `docs/os-on-arduino/code/06_memory_protection`
- ビルドと書き込み:

```bash
pio run -d 06_memory_protection -t upload
pio device monitor -b 115200
```

コードを見る: [docs/os-on-arduino/code/06_memory_protection](https://github.com/iory/learning-os-from-arduino/tree/main/docs/os-on-arduino/code/06_memory_protection)

## 実機での出力

Arduino UNO R4 WiFi の実機で実際に取得した出力です（macOS / Windows の
両方で同じ結果を確認しています）。手元の出力と見比べてください。

`d` を送ってゼロ除算タスクを作ると、そのタスクだけが `TERMINATED` になり、`Heartbeat` は動き続けます。

```{figure} ../_static/ch06_fault.gif
:name: fig-ch06-fault
:width: 100%

`p` でタスクを見て、`d` でゼロ除算を起こしたところ。fault のあとも
`Heartbeat` が途切れず、`Crash_Div` だけが `TERMINATED` になります
```

### シミュレータで見る

実機が無くても、同じファームウェアを {doc}`シミュレータ <../getting-started/simulator>` で動かすとこう見えます。

```{figure} ../_static/sim_ch06_fault.gif
:name: fig-ch06-sim
:width: 80%

`d` を送ると `Crash_Div` タスクがゼロ除算でフォールトを起こし、`FAULT DETECTED` と原因が出ます。そのあとも L（Heartbeat）の点滅と `[Heartbeat]` の出力は続きます。（シミュレータで撮影）
```
