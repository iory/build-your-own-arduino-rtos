# 第5章: 対話型シェル

シリアル越しに OS と会話するための小さなシェルを作ります。

## サンプルコード

- ディレクトリ: `docs/os-on-arduino/code/05_shell`
- ビルドと書き込み:

```bash
pio run -d 05_shell -t upload
pio device monitor -b 115200
```

コードを見る: [docs/os-on-arduino/code/05_shell](https://github.com/iory/learning-os-from-arduino/tree/main/docs/os-on-arduino/code/05_shell)

## 実機での出力

Arduino UNO R4 WiFi の実機で実際に取得した出力です（macOS / Windows の
両方で同じ結果を確認しています）。手元の出力と見比べてください。

`help` と `ps` を送ったところです。CPU% の合計がほぼ 100% になるのが、計測が正しく動いている目印です。

```text
help
Available commands:
  ps      - List all tasks
  kill N  - Suspend task N
  exec N  - Resume task N
  info    - System information
  reboot  - Reboot system
  help    - Show this help
> ps

ID  NAME           STATE      CPU%
--  ----           -----      ----
0   idle           READY     99%
1   LED1           BLOCKED   0%
2   LED2           BLOCKED   0%
3   Heartbeat      BLOCKED   0%
4   Shell          RUNNING   0%

> 
```
