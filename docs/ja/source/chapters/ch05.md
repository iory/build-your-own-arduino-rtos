# 第5章: 対話型シェル

シリアル越しに OS と会話するための小さなシェルを作ります。

## サンプルコード

- ディレクトリ: `code/05_shell`
- ビルドと書き込み:

```bash
pio run -d 05_shell -t upload
pio device monitor -b 115200
```

```{note}
サンプルコードは公開準備中です。公開され次第、このページから
リンクします。
```
