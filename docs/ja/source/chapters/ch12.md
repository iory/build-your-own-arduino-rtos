## 実機での出力

Arduino UNO R4 WiFi の実機で実際に取得した出力です（macOS / Windows の
両方で同じ結果を確認しています）。手元の出力と見比べてください。

A0 に可変抵抗をつなぐと値が動きます。`servo` は角度（度）です。

```text
pot(14bit)=3233  pot(10bit)=201  servo=34deg
pot(14bit)=3252  pot(10bit)=202  servo=34deg
pot(14bit)=3243  pot(10bit)=201  servo=34deg
pot(14bit)=3254  pot(10bit)=202  servo=34deg
pot(14bit)=3239  pot(10bit)=201  servo=34deg
pot(14bit)=3221  pot(10bit)=200  servo=34deg
pot(14bit)=3238  pot(10bit)=201  servo=34deg
pot(14bit)=3222  pot(10bit)=200  servo=34deg
...
```
