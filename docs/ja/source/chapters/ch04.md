# 第4章: プリエンプティブスケジューラ

SysTick を心臓にして、タスクを強制的に切り替えるスケジューラを作ります。

## サンプルコード

- ディレクトリ: `code/04_scheduler`
- ビルドと書き込み:

```bash
pio run -d 04_scheduler -t upload
pio device monitor -b 115200
```

コードを見る: [code/04_scheduler](https://github.com/iory/build-your-own-arduino-rtos/tree/main/code/04_scheduler)
