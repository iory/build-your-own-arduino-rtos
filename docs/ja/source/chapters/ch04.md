# 第4章: プリエンプティブスケジューラ

SysTick を心臓にして、タスクを強制的に切り替えるスケジューラを作ります。

- ディレクトリ: `docs/os-on-arduino/code/04_scheduler`
- ビルドと書き込み:

```bash
pio run -d 04_scheduler -t upload
pio device monitor -b 115200
```

## 実機での出力

Arduino UNO R4 WiFi の実機で実際に取得した出力です（macOS / Windows の
両方で同じ結果を確認しています）。手元の出力と見比べてください。

`Heavy` が重い計算を回している最中も、1 秒周期の `Count` が乱れません。これがプリエンプションの効果です。

```{figure} ../_static/ch04_preemption.gif
:name: fig-ch04-preemption
:width: 100%

`Count` がきっちり 1 秒ごとに出続け、その合間に `Heavy` が割り込まれている
ところ。実機の Arduino UNO R4 WiFi で録ったものです
```

```text

Heavy task completed iteration, sum=1783293664
```

### シミュレータで見る

実機が無くても、同じファームウェアを {doc}`シミュレータ <../getting-started/simulator>` で動かすとこう見えます。

```{figure} ../_static/sim_ch04_blink.gif
:name: fig-ch04-sim
:width: 80%

L（LED1）が 100ms ごと、マトリクス左半分（LED2）が 500ms ごとに点滅し、右半分は重い計算の `Heavy` タスクが 1 周するたびに切り替わります。`Heavy` が CPU を回し続けている最中も、L と左半分の点滅は乱れません。（シミュレータで撮影）
```
