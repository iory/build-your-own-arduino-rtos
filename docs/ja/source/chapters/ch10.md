# 第10章: FreeRTOSで同じことをやってみる

自作 OS と同じ課題を FreeRTOS で書き、設計の違いを比べます。

## サンプルコード

- ディレクトリ: `docs/os-on-arduino/code/10_freertos`
- ビルドと書き込み:

```bash
pio run -d 10_freertos -t upload
pio device monitor -b 115200
```

コードを見る: [docs/os-on-arduino/code/10_freertos](https://github.com/iory/learning-os-from-arduino/tree/main/docs/os-on-arduino/code/10_freertos)
