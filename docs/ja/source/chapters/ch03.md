# 第3章: コンテキストスイッチの実装

タスクの実行状態を保存・復元する仕組みを PendSV 例外の上に実装します。

## サンプルコード

- ディレクトリ: `code/03_context_switch`
- ビルドと書き込み:

```bash
pio run -d 03_context_switch -t upload
pio device monitor -b 115200
```

コードを見る: [code/03_context_switch](https://github.com/iory/build-your-own-arduino-rtos/tree/main/code/03_context_switch)
