## 実機での出力

Arduino UNO R4 WiFi の実機で実際に取得した出力です（macOS / Windows の
両方で同じ結果を確認しています）。手元の出力と見比べてください。

`os_yield()` で 3 つのタスクが切り替わります。

```{figure} ../_static/ch03_yield.gif
:name: fig-ch03-yield
:width: 100%

`Task1` → `Task2` → `Task3` と譲り合いながら回り続けるところ。
1 秒あたり 8 周ほどしているので、かなりの速さで流れます
```
