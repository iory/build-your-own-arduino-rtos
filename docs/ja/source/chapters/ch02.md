# 第2章: ベアメタルからの出発

Arduino のフレームワークに頼らず、レジスタ直叩きで LED を点滅させるところから始めます。

## サンプルコード

- ディレクトリ: `code/02_baremetal`
- ビルドと書き込み:

```bash
pio run -d 02_baremetal -t upload
pio device monitor -b 115200
```

コードを見る: [code/02_baremetal](https://github.com/iory/build-your-own-arduino-rtos/tree/main/code/02_baremetal)

## 実機での出力

Arduino UNO R4 WiFi の実機で実際に取得した出力です（macOS / Windows の
両方で同じ結果を確認しています）。手元の出力と見比べてください。

協調的スケジューラが 3 つのタスクを順に回しています。`Sensor value` は可変抵抗をつないでいなければ端子が拾うノイズです。

```text
[2500ms] Running: LED
  LED toggled
[2500ms] Running: Servo
  Servo angle: 70
[2600ms] Running: Servo
  Servo angle: 80
[2600ms] Running: Sensor
  Sensor value: 219
[2700ms] Running: Servo
  Servo angle: 90
[2800ms] Running: Servo
  Servo angle: 100
[2800ms] Running: Sensor
  Sensor value: 219
...
```
