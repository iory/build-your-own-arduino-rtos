# 第7章: LEDマトリクス可視化

UNO R4 WiFi 内蔵の LED マトリクスに OS の内部状態を表示します。

## サンプルコード

- ディレクトリ: `code/07_led_matrix`
- ビルドと書き込み:

```bash
pio run -d 07_led_matrix -t upload
pio device monitor -b 115200
```

コードを見る: [code/07_led_matrix](https://github.com/iory/build-your-own-arduino-rtos/tree/main/code/07_led_matrix)

## 実機での出力

Arduino UNO R4 WiFi の実機で実際に取得した出力です（macOS / Windows の
両方で同じ結果を確認しています）。手元の出力と見比べてください。
```text
ps

ID  NAME           STATE      CPU%
--  ----           -----      ----
0   idle           READY     50%
1   LED            BLOCKED   0%
2   Light          BLOCKED   0%
3   Heavy          READY     49%
4   Shell          RUNNING   0%
5   Display        READY     0%

> 
```
