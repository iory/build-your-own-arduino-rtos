# 第7章: LEDマトリクス可視化

UNO R4 WiFi 内蔵の LED マトリクスに OS の内部状態を表示します。

## サンプルコード

- ディレクトリ: `code/07_led_matrix`
- ビルドと書き込み:

```bash
pio run -d 07_led_matrix -t upload
pio device monitor -b 115200
```

コードを見る: [code/07_led_matrix](https://github.com/iory/build-your-own-arduino-rtos/tree/main/code/07_led_matrix)
