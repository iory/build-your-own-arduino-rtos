## 実機での出力

Arduino UNO R4 WiFi の実機で実際に取得した出力です（macOS / Windows の
両方で同じ結果を確認しています）。手元の出力と見比べてください。

REPL に `print(1 + 2)` と再帰関数を打ち込んだところです。`TP_MAX_SCOPES`（8）を超える深さの再帰は `RecursionError` になります。

```{figure} ../_static/ch11_repl.gif
:name: fig-ch11-repl
:width: 100%

ボード上の REPL に関数を定義して呼ぶところ。`fact(7)` は 5040 を返し、
`fact(30)` は `RecursionError` で止まります
```

```text
print(1 + 2)
3
>>> def fact(n):
...     if n < 2:
...         return 1
...     return n * fact(n - 1)
... 
>>> print(fact(7))
5040
>>> print(fact(30))
RecursionError: maximum recursion depth exceeded
0
>>> print(42)
42
>>> 
```
