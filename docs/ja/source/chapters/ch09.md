# 第9章: 統合とロボット制御

ここまでの部品を組み合わせ、OS の上でロボット制御タスクを走らせます。

## サンプルコード

- ディレクトリ: `code/09_integration`
- ビルドと書き込み:

```bash
pio run -d 09_integration -t upload
pio device monitor -b 115200
```

コードを見る: [code/09_integration](https://github.com/iory/build-your-own-arduino-rtos/tree/main/code/09_integration)

## 実機での出力

Arduino UNO R4 WiFi の実機で実際に取得した出力です（macOS / Windows の
両方で同じ結果を確認しています）。手元の出力と見比べてください。
```text
ps

ID  NAME           STATE      CPU%
--  ----           -----      ----
0   idle           READY     100%
1   Heartbeat      BLOCKED   0%
2   Sensor         BLOCKED   0%
3   Servo          BLOCKED   0%
4   LED_Ind        BLOCKED   0%
5   Button         BLOCKED   0%
6   Shell          RUNNING   0%
7   Display        BLOCKED   0%

> 
```
