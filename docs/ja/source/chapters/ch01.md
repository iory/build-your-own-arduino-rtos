# 第1章: ブートシーケンス

リセット直後の CPU が何をするかを追いかけ、ベクタテーブルから main() に至る道筋を自分の手でたどります。

## サンプルコード

- ディレクトリ: `code/01_boot`
- ビルドと書き込み:

```bash
pio run -d 01_boot -t upload
pio device monitor -b 115200
```

コードを見る: [code/01_boot](https://github.com/iory/build-your-own-arduino-rtos/tree/main/code/01_boot)
