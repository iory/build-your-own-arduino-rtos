## 実機での出力

Arduino UNO R4 WiFi の実機で実際に取得した出力です（macOS / Windows の
両方で同じ結果を確認しています）。手元の出力と見比べてください。

`run FORWARD 10` と `run PRINT hello` を送ったところです。

```{figure} ../_static/ch08_interpreter.gif
:name: fig-ch08-interpreter
:width: 100%

自作インタプリタにコマンドを打ち込んでいるところ。`PRINT` は
`[Print]`、`FORWARD` は `[Motor]` に届きます
```

```text
run FORWARD 10
[Interpreter] Loaded 1 lines

[Interpreter] Starting script...
[Motor] Forward 10 units
[Interpreter] Script completed: 1 commands executed
> run PRINT hello
[Interpreter] Loaded 1 lines

[Interpreter] Starting script...
[Print] hello
[Interpreter] Script completed: 1 commands executed
> 
```
