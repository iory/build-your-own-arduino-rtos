## 実機での出力

Arduino UNO R4 WiFi の実機で実際に取得した出力です（macOS / Windows の
両方で同じ結果を確認しています）。手元の出力と見比べてください。

`run FORWARD 10` と `run PRINT hello` を送ったところです。

```{figure} ../_static/ch08_interpreter.gif
:name: fig-ch08-interpreter
:width: 100%

自作インタプリタにコマンドを打ち込んでいるところ。`PRINT` は
`[Print]`、`FORWARD` は `[Motor]` に届きます
```

```text
run FORWARD 10
[Interpreter] Loaded 1 lines

[Interpreter] Starting script...
[Motor] Forward 10 units
[Interpreter] Script completed: 1 commands executed
> run PRINT hello
[Interpreter] Loaded 1 lines

[Interpreter] Starting script...
[Print] hello
[Interpreter] Script completed: 1 commands executed
> 
```

### シミュレータで見る

実機が無くても、同じファームウェアを {doc}`シミュレータ <../getting-started/simulator>` で動かすとこう見えます。

```{figure} ../_static/sim_ch08_led.gif
:name: fig-ch08-sim
:width: 80%

`LED` タスクが L を 500ms ごとに反転させ続けるので、先に `kill 1` で止めてから、インタプリタで `run LED 13 1`（点灯）、`run LED 13 0`（消灯）を実行しています。`LED` タスクを止めないと、次の反転で上書きされます。（シミュレータで撮影）
```

## 改良版: `08_interpreter_v2`（書籍未掲載）

第8章の LED マトリクスの表示は第7章と同じもので、読み取りにくさも同じです
（{doc}`ch07` の「改良版」を参照）。そこで第7章の
[`07_led_matrix_v2`](https://github.com/iory/build-your-own-arduino-rtos/tree/main/code/07_led_matrix_v2)
と同じ表示とシェルの `top` を入れた改良版を
[`code/08_interpreter_v2`](https://github.com/iory/build-your-own-arduino-rtos/tree/main/code/08_interpreter_v2) に置きました。インタプリタとカーネルは本書と同じです。

| 行 | 中身（どれも 12 個で 100%、0.5 秒ごとに更新） |
|---|---|
| 0–1 | CPU 全体の負荷（idle 以外） |
| 2 | 空き |
| 3–7 | LED / Shell / Display / Light / Heavy の CPU 使用率 |

第8章のタスク（LED・Shell・Display）はどれもほとんど CPU を使いません。LED タスクの
反転も、インタプリタの `FORWARD` / `TURN` / `DELAY` も `os_sleep()` で眠って待つので、
眠っている間 CPU はほかのタスクに回ります。棒が動くように、第7章の改良版と同じ
Light（CPU を 20 ms 使っては 60 ms 眠る）と Heavy（眠らずに計算し続ける）を、本書の
3 つのタスクの後ろに足しました。LED・Shell・Display のタスク番号は本書と同じなので、
`kill 1` → `run LED 13 1` の手順もそのまま使えます。

```{raw} html
<video src="../_static/ch08_v2_top.mp4" poster="../_static/ch08_v2_top_poster.jpg"
       controls muted playsinline preload="metadata"
       style="width:100%; border-radius:8px;"
       aria-label="08_interpreter_v2 の実機のマトリクスと、端末の top を並べた動画"></video>
```

実機（UNO R4 WiFi）の `top` の値は次のとおりです。

| 操作 | CPU 全体 | 目に見えること |
|---|---|---|
| 起動直後 | 約 60% | Light（16%）と Heavy（40%）の行に棒 |
| `kill 5` | 約 24% | Heavy の棒が消え、全体の棒が縮む |
| `kill 4` | 約 4% | 残るのは `top` を描いている Shell だけ |
| `exec 4` / `exec 5` | 元に戻る | |

```{note}
`run` でスクリプトを実行している間は、`top` の表示が止まります。描き直すのがシェルの
入力待ちの中なので、スクリプトが終わるまで更新されません。マトリクスは表示のタスクが
描くので、その間も動きます。
```
