# 第13章: 四脚ロボットを歩かせる — Physical AI への一歩

自作 OS でサーボを制御し、四脚ロボットを歩かせます。組み立ては[四脚ロボットの組み立て](../hardware/index.md)を参照。

## サンプルコード

- ディレクトリ: `docs/os-on-arduino/code/13_quadruped`
- ビルドと書き込み:

```bash
pio run -d 13_quadruped -t upload
pio device monitor -b 115200
```

コードを見る: [docs/os-on-arduino/code/13_quadruped](https://github.com/iory/learning-os-from-arduino/tree/main/docs/os-on-arduino/code/13_quadruped)
