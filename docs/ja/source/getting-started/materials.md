# 準備するもの

## 必須

| 品目 | 数量 | 備考 |
|---|---|---|
| Arduino UNO R4 **WiFi** | 1 | Minima ではなく WiFi 版（LED マトリクス搭載） |
| USB-C ケーブル | 1 | データ通信対応のもの |
| PC | 1 | Windows / macOS / Linux いずれも可 |

```{warning}
UNO R4 には **Minima** と **WiFi** の 2 種類があります。本書で使うのは
LED マトリクスを搭載した **WiFi 版**です。購入時にご注意ください。
```
