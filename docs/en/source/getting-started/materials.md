# What You Need

| Item | Qty | Notes |
|---|---|---|
| Arduino UNO R4 **WiFi** | 1 | The WiFi variant (with the LED matrix), not the Minima |
| USB-C cable | 1 | Must support data |
| A computer | 1 | Windows / macOS / Linux |

```{warning}
There are two UNO R4 variants; this book uses the **WiFi** one.
```
