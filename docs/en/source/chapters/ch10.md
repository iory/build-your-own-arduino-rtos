## On the board

```{figure} ../_static/ch10_freertos.gif
:name: fig-ch10-freertos
:width: 100%

`10_freertos` running with the monitor open. The tasks are written against a
FreeRTOS-style API (`xTaskCreate` and so on) and run by a simple scheduler inside
`loop()`; the `[FreeRTOS Task]` task increments `Count` once a second.
```

```{figure} ../_static/ch10_freertos_real.gif
:name: fig-ch10-freertos-real
:width: 100%

The real-FreeRTOS `integrated` example, flashed with
`pio run -d 10_freertos_real -e integrated -t upload`. Every 2 s it prints the FreeRTOS
tick count, the free heap and the A0 reading. With nothing connected to A0, `Pot value`
floats around 200; with a potentiometer it follows the knob (0–1023).
```
